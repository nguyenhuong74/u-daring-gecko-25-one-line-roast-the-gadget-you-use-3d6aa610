One original line roasting a gadget used every day: the authenticator app whose six-digit code always rotates the moment you finish typing it.

## The line

> My authenticator app lets me type all six digits, then changes the code — security with a sense of humour.

## Why the joke works

The setup is a daily ritual everyone with two-factor auth knows: copying a six-digit code before its 30-second window runs out. The punch is the timing — the code changes exactly when you finish typing, as if the security tool itself were playing a joke on you. It is one person's specific gripe (the code rotation, not a generic "apps are annoying") with a concrete detail about how the thing actually behaves.

## Run it

```sh
node main.ts
```

`main.ts` (Node 22, no dependencies) validates the line (1–200 characters, non-blank, single line, no leading/trailing whitespace) and writes it to `/output/entry.txt` with no trailing newline. It uses no network and no randomness, so every run produces byte-identical output.
